## How Run Project

first install dependencies:
``` bash
npm install
```

and then you can run project in development mode:
``` bash
npm run dev
```

Now you can see in your browser from this link => *http://localhost:3000*


## Build
For build just run this command:
``` bash
npm run build
```


and then, you can run project from your build with this command:
``` bash
npm start
```
